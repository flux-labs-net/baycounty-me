# Upcoming meetings data

`fetch_meetings.py` builds `meetings.json`, which holds upcoming public meetings for Bay County governing boards. It uses only the Python 3 standard library and no API keys.

```
python3 data/meetings/fetch_meetings.py            # today .. +60 days
python3 data/meetings/fetch_meetings.py --days 90 --out /tmp/m.json
```

A full run takes about one minute. Every source sits in its own try/except block, so a failing site adds an entry to `errors` and the run continues. The output file is written atomically, which means a crashed run never leaves a half-written `meetings.json`.

## Output shape

- `boards[]` has these fields: `id`, `name`, `gov` (one of county, pc, pcb, lh, cw, sp, parker, mb or schools), `schedule` (plain English), `schedule_source_url`, `location`, `source_url` and `calendar_url`. It also has `sources`, which records how each source did on this run, and `coverage`, which counts posted, calendar and expected meetings.
- `meetings[]` has these fields: `board`, `title`, `start`, `location`, `agenda_url`, `packet_url`, `minutes_url`, `source` and `status`. Some records also have `detail_url`, `calendar_source`, `past`, `expected`, `cancelled`, `time_from_schedule` and `items`.
  - `start` is an ISO local time with a Central offset: `-05:00` during CDT and `-06:00` during CST. All of Bay County, including Mexico Beach, is on Central time. If no time is known, `start` is a plain date.
  - `status` has three values:
    - `posted`: the meeting is listed by an official agenda system or by the board's own meetings page.
    - `calendar`: the meeting is posted on the government's website calendar (CivicPlus iCal) but has no agenda yet.
    - `expected`: the script generated the date from the regular schedule. These records also have `expected: true` and never have links.
  - `past: true` marks the most recent past meeting for each board. Cancelled meetings are skipped when picking it.
  - `items` holds best-effort "money items" as `{title, amount}`. They come from agenda items that mention a $ amount, contract, bid, budget, millage, purchase, award, change order, grant or RFP/ITB. They are extracted only where the agenda is available as HTML or JSON (PrimeGov, CivicClerk, Panama City AgendaCenter `?html=true`). PDF-only agendas get no items. `amount` is the first dollar figure in the item, or null.
  - `agenda_items` holds every agenda item title (procedural items such as call to order, invocation and reports, and section headings, are left out) from the same sources as `items`. For Lynn Haven, when CivicClerk's structured agenda has no items yet, the numbered items are read from CivicClerk's plain-text agenda file (`GetMeetingFileStream(fileId=N,plainText=true)`). These power keyword alerts (for example a street name) and search.

## How sources combine

For each board, the script first takes meetings from its agenda feed. It then merges in calendar entries that fall on the same date, using them to fill in a missing time or location. Calendar dates with no agenda entry are added as `calendar`. Expected dates are generated only for boards with no official calendar feed (PCB, Mexico Beach and Parker), and only on dates that nothing else already covers.

## Notes for automation

- To refresh daily, run `python3 data/meetings/fetch_meetings.py` from cron or CI, then commit `meetings.json` if it changed.
- Treat records with `expected: true` and `time_from_schedule: true` as provisional, and label them in the UI ("Expected – not yet posted").
- The money-item filter matches keywords, so it has false positives (for example a "budget amendment" with no dollar figure) and misses PDF-only boards. Treat it as a pointer to the agenda, not as data.
