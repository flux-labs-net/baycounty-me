How this site works

Public records only

Figures come from audits, adopted budgets, annual reports, council resolutions and local reporting. If a number is not in a record, it is not on the site.

Sources on every row

Each payment, grant or contract links to the document it came from, so you can check it yourself.

Gaps stated plainly

Where a city does not publish something, such as a check register, the page says so and names the record to request.
