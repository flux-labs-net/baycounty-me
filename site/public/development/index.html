The simple version

How a project gets built

  1. Zoning says what can go where. Changing it (a rezoning or land use change) takes a public hearing before the planning board and a vote of the commission. Those votes are on How they voted and the agendas on Meetings.
  2. A site plan gets a development order. Bigger projects such as shopping centers, subdivisions and apartments file a site plan. Planning staff review it against the rules and issue a development order when it passes.
  3. Then come building permits. Each building needs a permit and inspections. The Census Bureau counts the new homes those permits allow every month, which is the yearly count below.

Bay County's map covers the unincorporated county, where the county is the planning authority. Panama City Beach's map was last updated in 2022, so its newer projects are missing, and the other cities don't publish a development map. Owners and developers are not named on these maps; where a project has exactly the name of one active business filing, its card names that business.

Where this comes from

  • New homes: the U.S. Census Bureau's Building Permits Survey, which every permit office reports to monthly. Yearly files for 2016 on, and this year's file through the latest month posted. Checked weekly.
  • Bay County development orders (unincorporated county): the government's public planning map, read weekly. See its planning page. Projects with no date, or nothing on record since 2016, are left out.
  • Panama City Beach developments (city map layer): the government's public planning map, read weekly. See its planning page. Projects with no date, or nothing on record since 2016, are left out.
  • Individual building permits are in each government's permit portal. Bay County's portal asks for a picture code before every search, so permits are not copied here one by one; the Census counts above are the same permits, totalled.
  • Data: housing-permits (CSV) · development-projects (CSV).
